# TodoList 跨平台待办事项应用

一个极简、无广告、无需登录的跨平台待办事项管理应用，参考 Microsoft Todo，数据默认存储在本地。支持桌面端与安卓移动端，帮助用户高效管理日常任务和项目。

## 📋 项目简介

TodoList是一款真正跨平台的待办事项管理应用，基于Python和Web技术开发，同时支持桌面端（Windows、macOS、Linux）和移动端，提供直观的用户界面和丰富的功能，帮助用户在不同设备上无缝管理个人任务。

## ✨ 核心功能

| 模块 | 说明 |
|---|---|
| 任务管理 | 新建、编辑、删除、查看、完成待办；支持标题、描述、优先级、截止时间与提醒 |
| 周期任务 | 支持每天/每周/每月/每年、多时间点、间隔提醒、按次数/结束日期/永不截止，并支持 cron 表达式 |
| 分类与标签 | 支持分类管理、标签管理、标签编辑；支持多标签、多关键词“或”搜索 |
| 子任务 | 支持嵌套子任务，任务旁显示「📋」标识，可快速展开查看 |
| 附件 | v1.2.0 新增，支持关联文件、文件夹和在线链接 |
| 批量导入 | 内嵌类 Excel 表格：从 Excel/WPS 整块粘贴（TSV 自动分列分行）、框选复制/清空、Tab/Enter 键盘导航、自动追加行；也可直接从 Excel 文件导入 |
| 桌面插件 | 桌面置顶小窗显示「未完成」数量与「剩余倒计时」；可自选显示任务的优先级范围（四档多选）与倒计时区间（今日/明日/本周/本月） |
| 快捷操作 | `Ctrl + Space` 快速新建；`#` 标签、`@` 截止时间、`*` 分类，支持 Tab 补全分类 |
| 视图管理 | 列表视图、日历视图、时间轴视图、统计视图；时间轴支持拖拽修改截止时间 |
| 数据与同步 | SQLite 本地存储、数据导出、局域网共享、WebDAV/坚果云同步、自定义存储路径；支持增量上传、上传频率可选、换库安全保护 |
| 个性化 | 深色/浅色/自定义主题、中英文切换、窗口置顶、开机启动、快捷键配置、窗口自适应 |
| 平台支持 | 桌面端：Windows、macOS、Linux；移动端：Android、iOS（macOS/Linux/iOS 未充分测试） |

## 🆕 新增功能

### 一键启动（Windows）

根目录提供 `start.bat`，双击即可启动，无需命令行：

1. 自动定位可用的 Python 解释器（找不到时回退到系统 `PATH`）
2. 自动检测依赖，缺失时执行 `pip install -r requirements.txt`
3. 启动应用；退出码非 0 时保留窗口显示错误信息，便于排查

### 类 Excel 批量导入

点击侧边栏的「批量导入」不再依赖外部文件，直接弹出内嵌表格，操作方式与 Excel 一致：

- **整块粘贴**：在 Excel/WPS 中选中区域复制，粘贴到表格即自动按行分列填入，行数不足自动追加
- **表头识别**：粘贴内容首行若是「标题/优先级/分类/截止日期/时间」等表头，自动跳过
- **框选与键盘导航**：拖拽或 `Shift + 点击` 扩展矩形选区，`Delete` 清空选区；`Tab`/`Enter` 四向移动，末行按 `Enter` 自动新增行
- **复制/剪切**：选区可序列化为 TSV 写回剪贴板，方便与 Excel 双向搬运
- **列序固定**：标题 / 优先级 / 分类 / 截止日期 / 时间，解析规则与 Excel 文件导入完全一致；原有的「从 Excel 文件导入」保留为次要入口

### 桌面数据插件

桌面端可常驻一个无边框置顶小窗（默认 360×120，宽高比固定 3:1，左格恰为正方形），随时查看待办状态。点击侧边栏标题右侧的插件图标即可显示/隐藏：

- **左格**：所选优先级范围内的**未完成**任务数
- **右格**：按优先级显示一种状态 —— 存在逾期任务时显示「已逾期 N 个」；否则显示距最近一条任务的**剩余倒计时**（`hh:mm:ss`）；两者都没有时显示「无事发生」
- **双击插件**可将主窗口带到前台
- **二级设置**（设置中心 → 桌面插件）：
  - 显示任务范围：高 / 中 / 低 / 无优先级，四档开关，可同时开启
  - 倒计时区间：今日 / 明日 / 本周内 / 本月内
  - 入口右侧实时显示当前配置摘要，未完成任务数的统计口径与所选范围保持一致

### WebDAV 同步增强

| 改进 | 说明 |
|---|---|
| 上传频率可选 | 设置中心新增「上传频率」：默认（变更后 1 秒）/ 每 1 小时 / 关闭软件时；拉取频率默认 15 秒 |
| 增量上传 | 上传前先比对云端文件清单，**只传有变化的文件**，未变化的附件不再重传（附件多、使用坚果云等限额网盘时显著省流量） |
| 变更上传防抖 | 连续编辑（如批量导入 20 条）只在停手后上传一次，不再逐条触发 |
| 换库安全保护 | 从云端拉取数据库时先落盘临时文件，再挂起本地只读连接、备份、原子替换并做完整性校验，失败自动回滚；主库上传前强制 WAL 落盘，避免边车文件套用导致数据损坏 |
| 下载请求精简 | 整目录同步改为一次清单扫描，取消逐文件探测请求，文件较多时同步明显加快 |

### 自定义主题配色修正

自定义配色改为「背景系从背景色派生、文字系从文字色派生」，两者互不影响：调整字体颜色不再连带改变背景与边框，调整背景色也能正确作用于各级背景层次。

### 稳定性修复

- 自动同步的定时链在停止后不再「复活」，避免停止后仍在上传或出现双定时器并发
- 配置文件改为「临时文件 + 原子替换」写入，异常退出不会留下半截配置
- 逾期判定口径统一（截止时间精确到秒比较），逾期任务可正常编辑
- 桌面插件读取失败时自动降级显示，不影响主程序运行

## 🚀 快速开始

### 桌面端安装

**环境要求**：
- Python = 3.10.9

**安装步骤**：
```bash
# 1. 克隆项目（如果从仓库）
git clone <repository-url>
cd TodoList

# 2. 安装Python依赖
pip install -r requirements.txt

# 3. 启动应用
python main.py

# 4. 打包应用生成exe(可选)
python build.py
```

*\*说明：build脚本使用默认图标，可以通过scripts/utils/create_icon.py生成自定义图标置于根目录即可自动打包到exe中。*

**Windows 一键启动**：首次安装依赖后，直接双击根目录的 `start.bat` 即可启动，脚本会自动检测并补装缺失依赖。

### 安卓移动端安装

**方式一：云端构建（推荐，Windows 无需装任何环境）**

把项目推到 GitHub，用仓库内置的 `.github/workflows/android.yml` 在 GitHub Actions 的 Linux 服务器上编译，产出 APK 后直接下载安装。全程只需「推送 → 点按钮 → 下载」，第一次约 40～70 分钟，之后有缓存约 15～25 分钟。

📖 **手把手图文步骤见 [`安卓打包详细步骤.md`](安卓打包详细步骤.md)**（含账号注册、上传代码、触发构建、下载安装、报错对照表）

**方式二：本地构建 APK**

> ⚠️ **Buildozer 只能运行在 Linux 上**，Windows 无法直接打包。Windows 用户请先安装 **WSL2 + Ubuntu 22.04**，在 WSL 里执行下面的命令（源码建议复制到 WSL 家目录再构建，直接放 `/mnt/c/...` 会非常慢）。
>
> 也可以直接跑 `bash scripts/build_android.sh`：该脚本会自动把 `scripts/config/buildozer.spec` 同步到项目根目录并做配置自检，再启动 buildozer。

**方式三：使用预构建 APK**

1. 从项目发布页面下载最新 APK。
2. 在安卓设备上启用「未知来源」安装。
3. 安装并打开应用。

**环境要求**：Linux、Python 3.11（p4a v2024.01.21 自带）、Buildozer、Android SDK + NDK（首次构建由 Buildozer 自动下载，约 2–3 GB）

**构建步骤**：
```bash
# 1. 安装构建工具（WSL Ubuntu 内执行）
sudo apt update && sudo apt install -y python3-pip openjdk-17-jdk zip unzip git
pip3 install --user buildozer cython==0.29.36

# 2. 构建 APK（脚本会自动把 scripts/config 里的配置同步到项目根目录）
bash scripts/build_android.sh

# 3. 安装到手机（手机需开启「开发者选项 → USB 调试」）
adb install -r bin/todolist-*-debug.apk
```

*\*说明：构建配置维护在 `scripts/config/buildozer.spec`，其中 `p4a.source_dir`、`android.add_jars` 等与原开发者机器绑定的项已注释，交由 Buildozer 自动处理。*

**安卓端功能差异**（移动端没有本地文件系统与桌面环境）：

- 附件只同步关联信息，不同步实体文件；WebDAV 同步仍可用
- 不支持导出 Excel、系统托盘、全局快捷键、桌面数据插件
- 截止时间提醒改为写入系统日历（首次使用会申请日历权限）

### 换电脑 / 备份数据

数据全部在**存储目录**下的 `todolist` 文件夹里，与程序目录无关（升级、重装、换机器都不会丢）。设置 → 数据 → 「存储目录」那一行显示的路径就是它。

| 内容 | 位置 | 换电脑要拷吗 |
|---|---|---|
| 任务、分类、标签、关系、日历事件 | `<存储目录>\todolist\todo.db` | ✅ 必须 |
| 附件实体文件 | `<存储目录>\todolist\attachment\` | ✅ 有附件就必须 |
| 设置、主题、WebDAV 账号、存储目录偏好 | `%APPDATA%\TodoList\app_config.json` | ⭕ 可选（建议只拷 `todo.db` + `attachment`，让新机器重新选存储目录更稳） |
| 运行日志 | 打包版在 exe 同级的 `logs\` | ❌ 不需要，只是排错用的文本日志，不含任何任务数据 |

**默认位置**：未手动改过存储目录时是 `%APPDATA%\TodoList\todolist\`（开始菜单搜索 `%APPDATA%` 回车即可打开）。

**正确做法**：

1. 先在托盘右键**完全退出**软件（数据库是 WAL 模式，运行中直接拷贝可能拷到不完整的状态）
2. 把整个 `todolist` 文件夹复制到 U 盘 / 网盘
3. 新电脑上先启动一次软件让目录建好，退出，再用复制来的 `todolist` 文件夹**覆盖**同名文件夹
4. 重新打开软件，任务和附件都在

> 换电脑后想两台机器共用同一份数据，用内置的 **WebDAV 同步**（设置 → 同步）比手动拷文件夹更安全。

## 🔧 技术栈

- **前端**：HTML5 + CSS3 + JavaScript (ES6+)
- **桌面框架**：Python + PyWebView
- **后端**：Python 3.10.9
- **数据库**：SQLite（本地存储）
- **构建工具**：Buildozer(用于构建安卓应用) + PyInstaller(用于桌面构建)

## 📁 项目结构

```
TodoList/
├── backend/           # 后端API和数据库操作
├── frontend/          # 前端界面和交互逻辑
├── data/             # 应用数据根目录（可自定义存储位置）
├── todolist/         # 本地数据库 todo.db 与附件目录
├── scripts/          # 脚本归档
├── TodoList.spec     # PyInstaller配置文件（用于桌面构建）
├── build.py          # 桌面端应用构建脚本
├── main.py           # 桌面端应用启动脚本
├── start.bat         # Windows 一键启动脚本
├── requirements.txt  # 项目所需的依赖包
└── README.md         # 项目说明
```

*\*说明：启动项目核心仅需要backend目录、frontend目录和main.py即可。*

*\*注意：`todolist/todo.db` 即本地任务数据，请勿用压缩包解压覆盖的方式更新项目，否则会连数据一起被替换；升级前建议先备份该文件。*
